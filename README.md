# HAI101

Single-page website for **HAI101 | Human x Artificial Intelligence**, a lecture series hosted by
CPNSS at the London School of Economics. Built with React + Vite.

## Develop

```
npm install
npm run dev
```

All content (series info, schedule, speakers) lives in `src/data.js`. Speaker headshots are in
`public/img/speakers/` (640×800, named by speaker id) and institution logos in `public/img/logos/`.
